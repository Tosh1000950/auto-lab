# FLIPFILL（フリップフィル）

Auto Lab 第5弾（オートラボ2、2026-11-27 開始）の新作抽象戦略ゲーム。

- ルール：5×5、置くと隣接する敵石が全部返る、25手で終了、多数決、引き分けなし。パイ（スワップ）ルールで先手有利を調整。
- index.html：遊べる簡易版（対・簡易AI）＋事前計算 v1 の初手マップ＋厳密ソルバーの確認結果。
- data.json：Colab 計算（2026-11-27）の要約。全25初手のランダムプレイアウト勝率（20万局/初手）とヒューリスティクス混ぜプレイアウト勝率（3,000局/初手）、厳密解チェック5件の要約。
- 設計と経過：作業正本は ~/workspace/autolab2-20261127/（DESIGN.md / PROGRESS.md）。計算ノートブックは Google Colab（Drive保存）。
- 初回の発見：ランダムプレイアウトでは先手勝率は全初手で 0.715〜0.723 とほぼ一定で、先手有利は初手の位置より手番構造由来の可能性が高い。
