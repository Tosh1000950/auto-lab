# FLIPFILL（フリップフィル）

Auto Lab 第5弾（オートラボ2、2026-11-27 開始）の新作抽象戦略ゲーム。

- ルール：5×5、置くと隣接する敵石が全部返る、25手で終了、多数決、引き分けなし。パイ（スワップ）ルールで先手有利を調整。
- index.html（v3、2026-11-28）：遊べる盤面（AI対戦／2人対戦、どちらもスワップ実装。AIは終盤に厳密ソルバー使用）、解析盤（空き10以下は証明済み表示、それ以外は統計推定表示）、定跡本 v1 の応手表と初手マップ。v3で中央配置＋木盤・石の質感、3D反転（200ms・近い順に約45msスタッガ・速いペースで自動短縮）、Web Audio合成の打石音（3層クラック、反転音は小さく高く短く、ミュート永続化）を追加。AI音声生成と写真テクスチャは深度検索の結果不採用。
- v4（11-28朝）：本人の指摘で改修。①初手が角だとAIスワップ後に盤が再描画されず固まるバグを修正。②コマを半球状の石から「裏返せば色が変わる両面コマ」（厚み・側面・同心溝つき）に描き直し、現実版の遊び方（紙の盤＋リバーシ用コマ25個）を明記。③AI難易度3段階（弱い／普通／強い＝空き11以下完全読み＋MCTS）を追加。④コマの意匠2種（白黒／紋様）を追加。
- v5（11-28朝）：「合成音がチープ」との本人の感想を受け、打石音を実録に差し替え。Kenney Impact Sounds（CC0、ハッシュ検証済み）の impactWood_medium／light から着手3テイク・反転2テイクを切り出し（計10ファイル・約80KB、ogg＋mp3）。再生時にテイクのランダム選択とピッチの微揺らし、反転は連なるほど再生速度アップ。合成音はフォールバックとして残置。
- data.json：Colab 計算（2026-11-27）の要約。全25初手のランダムプレイアウト勝率（20万局/初手）とヒューリスティクス混ぜプレイアウト勝率（3,000局/初手）、厳密解チェック5件の要約。
- book.json：定跡本 v1（2026-11-28、ローカルMCTS）。ルート60,000回＋応手40,000回×6ラインの探索結果と、対称クラス平均。
- 初回の発見：ランダムプレイアウトでは先手勝率は全初手で 0.715〜0.723 とほぼ一定。MCTSの対称平均でも隅72.4%・他70.4〜71.4%と幅は小さく、先手有利は初手の位置より手番構造由来の可能性が高い。
