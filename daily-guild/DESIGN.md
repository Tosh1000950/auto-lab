# まいにち冒険ギルド — ゲームデザイン文書

## 方針転換（2026-11-19 19:22 本人指示）
「早くコストが少なく作ればいいわけじゃない。制限なしで、とても良いものを作るのが目的」
→ 習作3本（ピタスト／発明スロット／クエスト手帳）の仕組みを統合し、**システム同士が噛み合う1本のゲーム**を旗艦作として作る。

## コンセプト
日常が冒険になるギルド運営ゲーム。朝に届く「日常クエスト」を、発明スロットで作った「発明品」を装備して攻略する。
発明の笑い（第2作）と、毎日の習慣（第3作）と、コード交換（Webpixmon の発想）が1つのループで回る。

## コアループ（1日5分）
1. 朝：その日全員共通のクエストが3つ届く（カテゴリと難易度つき）
2. 発明チケットで発明スロットを回し、装備（発明品）を手に入れる
3. クエストごとに発明品を割り当てて挑戦。成功率は「発明のパワー − クエストの要求値 ＋ 相性ボーナス」で決まる
4. 成功で EXP・コイン・チケット獲得。失敗しても EXP は少し入り、冒険ログに面白い顛末が残る（失敗を罰にしない設計）
5. 3つ全達成でボーナス。週に1度、週替わりボス「週末の大物」に所持発明の上位3つの合計パワーで挑める

## システムの噛み合わせ
- 発明（第2作の 6,400 通り）にレア度連動のパワーと、モノごとの「相性カテゴリ」を付け、ただのコレクションから「使える装備」に昇格させた。
- クエスト（第3作の 48 種）はカテゴリと難易度がそのまま要求値になる。
- 発明コードは「借りる」仕組みに転用：友達のコードを入れると、その発明を今日だけ借りられる。強い発明のコードが SNS で貸し借りされる導線。
- 判定ロールは日付×クエスト×発明コードから決定的に生成。リロードで振り直せない（ズル防止）代わりに、結果は誰が検証しても同じになる。

## バランス表
- 発明パワー：N=10〜20 / R=18〜28 / SR=30〜40 / UR=50〜60（レア度基礎値＋個体差0〜10）
- 相性ボーナス：発明のカテゴリ＝クエストのカテゴリで +15
- クエスト要求値：難易度★1=15 / ★2=30 / ★3=45
- 成功率：50 ＋ (パワー − 要求値) ＋ 相性15、範囲 10〜97%
  - 例：序盤の N 発明（15）で ★1（15）に挑むと 50%。相性が合えば 65%。最強の UR（60）でも ★3 では 80% が上限（相性込み）で、絶対に確定しない緊張感を残す。97% の上限に届くのは ★1 に強い発明を持ち込んだ時。※初版の設計メモにあった「UR で ★3 も 97%」は計算違いだったため検証時に訂正。
- 報酬：成功 EXP=20+難易度×10、コイン=5+難易度×5、チケット+1（クエストごと）。失敗 EXP=5、コイン=2。
- 全達成ボーナス：EXP+30、チケット+1。
- ボス：上位3発明の合計パワー 90 以上で挑戦可、成功率 = 40 + (合計−90)/2（上限95%）。成功で EXP+150、コイン+100、称号フラグ。
- チケット：初期3枚。発明1回=1枚消費。クエスト成功で戻ってくる設計なので、毎日回し続けられる。

## 冒険ログ（物語生成）
成功／失敗それぞれ文章テンプレートを用意し、クエスト名と発明名を差し込んで「今日の冒険譚」として残す。シェア文と画像カードはこのログから作る。ゲームの思い出が文章で残ることが、ただの数値ゲームと違う点。

## 継続の仕掛け
- 毎日変わるクエストと週替わりボス（再訪理由）
- 図鑑 6,400 件と UR 発明（コレクション）
- レベルと称号（成長の可視化）
- 友達の発明コードを借りる（人との接続）

## 技術
- 単一 HTML、外部依存ゼロ、localStorage 保存。データは第2作・第3作の実績あるバンクを再利用し、検証済みロジックの上に新システムを載せる。
