# 合体クラフト（製作中）

2つの要素を合体させて新しい要素を発見していく、日本語の組み合わせクラフトゲーム。
合体結果は「その場でAIが考える」のではなく、**Kaggle の無料GPU（T4×2）で日本語LLM（ELYZA-JP-8B）に事前に大量生成させ、審査で選別した固定グラフ**を使う。全員が同じ発見を辿れる＝図鑑のコンプリート率や「作り方」が成立するのが、ライブ生成型との違い。

## 状態（2026-11-27時点）

- Webアプリ（`index.html`＋`data.js`）：完成し、ロジック検証（Nodeスタブテスト）合格済み。ただし **現在の data.js は仮データ（スタブ）** で、本データへの差し替え待ち。
- 本データ生成：Kaggle ノートブック `gattai-craft-prod` の Version #2 がキュー待ち。キューが進めば自動で実行され、最大約9.5時間で最大11,000ペア分のレシピが生成される予定。完了後に `results_all.jsonl` 等を回収し、`src/build_graph.py` でグラフ化して `data.js` を差し替える。
- パイロット検証（120組）：ELYZA-JP-8B、候補3案＋モデル審査方式で 120/120 生成成功。良発見が安定して出ることを確認済み（土＋土→盆栽、土＋島→地図、太陽＋音→メロディ 等）。

## 遊び方（アプリ）

- 下のトレイから要素を2つタップすると合体する（同じ要素2つも可）
- 初めての結果は「新発見」。発見率は上部の進捗バーに表示
- 「要素ずかん」で発見済み／未発見（シルエット）を確認、要素をタップすると作り方が見える
- 進捗はブラウザに自動保存。進捗カードを画像でXに投稿できる
- まだ計算されていない組み合わせは、仮の姿（フォールバック要素）で返る。その旨は画面下部に明示している

## 仕組み

- 基礎要素55種から全ペアを生成→到達可能要素をBFSで広げ、未計算ペアを深さ順に生成する反復方式（`src/gen_prod.py`、Kaggle上で自己完結）
- 生成形式は「名前｜絵文字｜一言」の区切り形式＋候補3案をモデル自身が審査して1案に絞る
- 静的サイトとして配信し、運用コストはゼロ

## 車輪の再発明チェック

- 先行例：Infinite Craft（ライブLLM生成）。本作は再発明にあたるため、付加価値は次の4点：①固定グラフで全員が同じ発見を辿れる（図鑑・コンプリート率・作り方が成立）②日本の語彙と文化に寄せた要素設計 ③生成＋審査＋検証を通した均一な品質 ④静的配信で運用コストゼロ・オフライン可
