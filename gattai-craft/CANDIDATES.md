# 候補一覧と吟味（2026-11-27、深度検索＋水素＋Grok の入力を受けて）

## 入力の要点
- 深度検索：この方式（GPUで事前計算→静的サイト）で実証済みのバイラルは This Waifu Does Not Exist 型。勝ち筋は「Infinite Craft の探索感を、事前計算で静的に再現する」こと。**制約はGPU時間ではなく GitHub Pages の 1GB**。日本語圏の空白地帯として「日本語版 Infinite Craft（事前計算ペアグラフ）」「GPU生成図鑑」「日本語特化の小型ONNXモデル」「テキストコーパス系」が挙がった。T4×2 の実測目安：SDXL 約107枚/時、7B級LLM 約37〜43 tok/s（単一ストリーム）→ 週あたり短文ペア結果なら約2万件が射程。
- 水素：進化テラリウム／AI人狼／AlphaZero戦略ゲーム／認知バイアス診断／潜在空間シンセ／文明アトラス。警告「並べるだけのギャラリーは死ぬ。核は『ブラウザCPUでは100年かかる深さ』と手触り」。
- Grok：宇宙／生態系／歴史分岐／分身／壊れた物理／アートコロニー／人生分岐。警告は水素と一致（ギャラリー否定）。

## 本命 A の設計骨子
- 要素は日本語の語彙 約200〜400（自然・食べ物・動物・妖怪・ご当地・道具・概念…）。各要素に絵文字と、LLM生成の一言説明。
- 合体結果は Kaggle の GPU で 7B級日本語LLM（ELYZA-JP-8B 等）に生成させ、検証（結果が要素リスト内か、重複排除、NG自動フィルタ）を通してグラフJSON（10〜30MB）にする。
- 計算順序は開始要素からの BFS（到達可能性の深さ順）。プレイヤーが実際にたどる範囲は必ず本物データで埋め、予算が尽きた先は設計済みフォールバック（煙・残骸などの汎用結果）に逃がす。
- 画面：タップ2つで合体、発見図鑑（カテゴリ・検索・完成率）、結果カード＋X投稿（SHARE_MANUAL の標準仕様で実装）。
- なぜ化け物級か：①元ネタの探索中毒は実証済み ②日本語の事前計算版は検索範囲で未発見（深度検索の空白地帯1位） ③数万ペアの生成と検証は GPU なしには不可能で、ブラウザ側は軽い ④1GB 制約に余裕で収まる ⑤完成率と発見シェアが拡散の燃料になる。
- 最大のリスク：LLM の合体結果の質（支離滅裂・ループ・漢字ミス）。→ パイロットで 300 ペアほど生成して目視判定し、ダメなら C へ乗り換える。
