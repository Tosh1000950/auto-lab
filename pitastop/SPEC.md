# ピタスト！ (PitaStop) 仕様

## 企画（自動テストとして Muse が選定）
- 日替わり目標秒数にストップウォッチをピタッと止める、1回30秒で終わるデイリーゲーム。
- 選定理由: ルール説明が1行で済む／結果の「誤差○○ms」がそのままSNSで自慢・悔しがれる／毎日目標が変わるので再訪理由がある／素材ゼロ・単一HTMLで軽く、スマホ・PC両対応にできる。
- 想定シェア文が最初から設計に入っている（Wordle型のデイリー＋結果共有）。

## ルール
- モード: 「今日のチャレンジ」（1日3回まで、目標は日替わり）／「フリー練習」（無制限、目標を選べる）
- 目標候補: 5.00 / 6.66 / 7.77 / 8.88 / 9.99 / 10.00 / 11.11 / 12.34 秒。日付から決定的に1つ選ぶ（全員その日は同じ目標＝話題が揃う）。
- ブラインド: 目標の2秒前から表示が「??.??」に隠れる。最後は自分のカウント頼み。これが難しさと笑いの核。
- ランク: 誤差 0ms=神ピタ(SSS) / ≦50ms=SSS / ≦100ms=SS / ≦200ms=S / ≦350ms=A / ≦500ms=B / ≦1000ms=C / それ以外=D
- 記録: localStorage に当日の試行・ベスト誤差・連続プレイ日数（ストリーク）を保存。サーバーなし。
- 共有: Web Share API 優先、無ければクリップボードへコピー。共有文には日付・目標・ベスト誤差・ランク・試行ごとの近さ絵文字が入る。

## 技術
- 単一 index.html（外部依存ゼロ、約20KB想定）。タイマーは performance.now() ベース。
- ロジック関数（getDailyTarget / rankFor / shareText 等）は DOM から分離し、Node で単体テスト可能にする。
- 操作: ボタン／タップ／スペースキー。
