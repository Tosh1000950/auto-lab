# 日替わりクエスト手帳 制作経過ログ

置き場所: ~/workspace/daily-quest/ （全体の索引は ~/workspace/auto-test-20261119/INDEX.md）

## 企画
- 毎朝、その日専用の「小さな冒険クエスト」が3つ届く生活ゲーム化ツール。クエストは日付から決定的に選ばれるので、家族や友達と開けば全員同じ3つ（「今日のクエストやった？」が会話になる）。
- クエスト例：「いつもと違う道を通る」「誰かにありがとうを言う」「冷蔵庫の奥のものを食べる」。所要5〜15分、道具なし、失敗しても損しないものだけ48種。
- 仕組み：達成チェックで EXP 獲得 → レベルアップと称号（駆け出し冒険者→…→伝説の日常王）。連続達成日数（ストリーク）。1日1回だけクエストを1つ引き直せる「運命の書き換え」。過去7日の達成状況が点で見える。
- シェア：今日のクエストと達成数を文にして X 等へ。画像ではなく文ベース（軽さ優先）。
- 狙い：第1作（ゲーム）・第2作（ジェネレーター）とジャンルを分け、「役立つ寄り」を1本入れるポートフォリオ構成にした。
